# Instagram Login Page Clone

A responsive front-end recreation of an Instagram-style login page built with HTML, CSS, and JavaScript.

> **Note:** This project is created for learning and UI practice only. It is not affiliated with, endorsed by, or connected to :contentReference[oaicite:0]{index=0} or :contentReference[oaicite:1]{index=1}.

## Preview

The page includes:

- Instagram-style desktop login layout
- Left-side promotional section on desktop screens
- Responsive tablet and mobile design
- Username and password fields
- Password visibility toggle
- Login button
- Forgot password link
- Facebook login button UI
- Create account button
- Footer navigation and language selector

## Features

- Fully responsive layout using CSS media queries
- Desktop layout with a two-column grid
- Mobile and tablet layout with the promotional section hidden
- Accessible password visibility button using `aria-label`
- Input validation using HTML attributes
- Smooth hover and focus states
- Clean and reusable CSS structure
